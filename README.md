# Кабинет куратора

Прототип кабинета куратора на React и Vite: главная, список учеников, карточка ученика, оформление заморозки, календарь и создание задач.

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://localhost:5173

```sh
npm run build
```

Изображения и SVG из Figma находятся в `public/assets`. Bounded подключён локально; основной текст использует системный шрифт SF на macOS и системный fallback на других платформах.

На главной странице кнопка «Все студенты» открывает `/students`. На экране учеников работают поиск, вкладки статусов и фильтры семестра и группы. Стрелка в строке открывает правую панель с диалогом. Сообщение можно добавить локально в прототипе; серверная интеграция не подключена.

## Структура

- `src/main.jsx` — точка входа и подключение стилей.
- `src/App.jsx` — сборка приложения, переключение страниц и открытие панелей.
- `src/pages` — главная, ученики и календарь.
- `src/components` — сайдбар, строка ученика, портрет, иконки, диалоги и формы. Карточка ученика и заморозка лежат в собственных папках.
- `src/data` — демонстрационные студенты, переписка и события календаря. Поля студентов именованные: `name`, `group`, `direction`, `portrait` и т. д.
- `src/hooks` — навигация с обработкой истории браузера и сохранение событий календаря.
- `src/lib` — адреса локальных ресурсов и форматирование дат.
- `src/styles` — общие стили и отдельные файлы по экранам и компонентам. `index.css` сохраняет порядок каскада.

Маршруты: `#/`, `#/students`, `#/calendar`. Кнопки «Назад» и «Вперёд» синхронизируют экран с адресом. Открытый ученик определяется параметром `student` внутри hash-маршрута. Такие адреса работают при обновлении страницы на GitHub Pages.

Задачи хранятся в `localStorage` под ключом `mentor-calendar-events`; повреждённая или недоступная запись заменяется демонстрационными событиями. Сообщения и заморозка остаются состоянием прототипа, без отправки на сервер.

## Публикация и обновления

В настройках репозитория GitHub откройте **Settings → Pages → Source → GitHub Actions**.
Workflow `.github/workflows/deploy.yml` собирает и публикует сайт после каждого push в `main`. Адрес подпапки определяется автоматически из настроек Pages; изображения и шрифты используют тот же базовый путь.

После изменений:

```sh
git add .
git commit -m "Обновить прототип"
git push
```

Статус публикации доступен во вкладке **Actions**. Для локальной проверки сборки с подпапкой:

```sh
VITE_BASE_PATH=/mentor-dashboard/ npm run build
npm run preview -- --base /mentor-dashboard/
```

Открывайте `/mentor-dashboard/#/students` на адресе preview-сервера. Секреты, `.env`, `node_modules`, `dist` и служебная папка `.vercel` исключены из Git.
